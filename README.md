# Proyecto de Pruebas — Demoblaze (Entrega I)

Proyecto del curso **Construcción de Software y Pruebas** (Grupo A, 2026-2),
Pontificia Universidad Javeriana Cali. Profesora: Claudia Martínez.

**Sistema bajo prueba:** [Demoblaze](https://www.demoblaze.com) — tienda en línea
de demostración de BlazeMeter. Pruebas de **caja negra** (software de terceros, sin
acceso al código fuente).

## Integrantes
- Joshua Mendez
- Edinson Pedroza

## Contenido
- **`Proyecto-Entrega1.pdf`** — documento principal de la Entrega I (9 secciones:
  info general, descripción, arquitectura, actores, funcionalidades, reglas de
  negocio, plan de pruebas, casos de prueba con las 4 técnicas de caja negra, y
  reporte de resultados).
- **`documento/`** — fuentes LaTeX del documento principal.
- **`anexo-A-plan/`** — Plan de Pruebas completo y ejecutado (PDF + LaTeX + evidencias).
- **`anexo-B-suite/`** — Suite de casos de prueba en Excel (68 casos: 60 del plan + 8
  de arreglos ortogonales).
- **`evidencias-cp-ao/`** — Capturas de la ejecución de los casos de arreglos ortogonales.
- **`fuentes-md/`** — Borradores en Markdown de las secciones descriptivas.

## Técnicas de caja negra aplicadas
Partición de equivalencias · Análisis de valores límite · Tablas de decisión ·
**Arreglos ortogonales** (L8 de Taguchi sobre el formulario *Place Order*).
